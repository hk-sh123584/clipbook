# 剪贴簿 Clipbook

一个只在本地运行的 Windows 剪贴板历史工具。常驻系统托盘，随时唤出，把复制过的文字和图片都留在簿子里。

基于 Electron + React + TypeScript + Vite，数据全部存在本机，不联网。

## 功能

- **自动记录**：后台每 400ms 检查一次剪贴板，复制的文字和图片会自动收集，无需手动保存
- **截图也能留**：`Win+Shift+S` 截的图即使没存成文件，也会被记录
- **快速唤出**：全局快捷键 `Ctrl+Shift+V`，在任何软件里都能呼出，再按一次收起
- **搜索过滤**：输入关键词即时筛选，`/` 一键聚焦搜索框
- **重复内容去重置顶**：同一段文字或同一张图再次复制，只会移到最前面，不会存两份
- **自动分类标记**：链接和代码片段会显示对应标签
- **收藏置顶**：常用内容标星后固定在顶部，清理时优先保留
- **图片缩略图**：列表只加载最长边不超过 480×320 的缩略图，点击复制时取回的原图不受影响
- **长列表不卡**：虚拟滚动只渲染可见的几行，1000 条记录也很轻
- **低内存驻留**：窗口收起 5 秒后释放界面进程，只保留后台记录，占用约 105 MB
- **窗口可调**：拖拽右下角手柄改变大小，也可用右上角按钮最小化、最大化、关闭
- **关闭不等于退出**：点关闭只是收起窗口，剪贴板继续记录；要退出请用托盘菜单

## 使用方法

### 基本操作

| 操作 | 说明 |
| --- | --- |
| `Ctrl+Shift+V` | 唤出 / 收起窗口 |
| 点击任意记录 | 把内容写回剪贴板，窗口保持打开 |
| `↑` / `↓` | 上下选择 |
| `Enter` | 复制选中项 |
| `/` | 聚焦搜索框 |
| `Esc` | 有搜索词时先清空搜索，再按一次收起窗口 |
| `☆` / `★` | 收藏 / 取消收藏（置顶） |
| `✕` | 删除这一条 |
| `清空` | 清空全部历史，需要点两次确认 |

### 窗口

- 右下角的斜线手柄可拖拽调整宽高，最小 360×420，最大不超过当前屏幕工作区
- 右上角 `−` 最小化到托盘，`□` 最大化 / 还原，`✕` 关闭窗口（后台继续记录）
- 位置与大小在本次运行期间记忆，重启程序后回到默认位置

### 托盘菜单

右键托盘图标：

- 显示剪贴簿
- 清空历史
- 退出

托盘图标的位置由 Windows 决定。首次启动会自动放到任务栏可见区，之后你把它拖进折叠菜单或拖回任务栏，都会按你的选择保留。

## 数据存储

所有数据只在本机：

```
%APPDATA%\clipbook\
├── clips.json          # 记录列表
├── clips.json.bak      # 上一次写入的备份
├── images\             # 图片原图与缩略图（文件名是内容哈希）
└── tray-state.json     # 托盘位置是否已初始化
```

- 记录上限 1000 条，其中图片最多 100 张；超出时优先淘汰最旧的未收藏图片，并删除对应文件
- 删除记录、清空历史时，图片文件会一起清理
- 误删或文件损坏时，可把 `clips.json.bak` 复制为 `clips.json` 恢复上一份数据（先退出程序）

便携版每次启动会把程序解压到 `%TEMP%\clipbook-portable`，固定路径是为了让 Windows 能记住托盘图标位置。

## 开发

需要 Node.js 18 及以上。

```bash
npm install      # 安装依赖
npm run dev      # 开发模式，Vite + Electron 热更新
npm run build    # 类型检查 + 构建前端
npm run dist     # 打包成免安装 exe，输出到 release/
npm run icon     # 重新生成应用图标
```

### 目录结构

```
electron/
├── main.cjs      # 主进程：窗口、托盘、剪贴板轮询、图片处理、IPC
├── preload.cjs   # 暴露给渲染进程的安全接口
└── store.cjs     # 记录存储：去重、排序、上限淘汰、备份
src/
├── App.tsx       # 界面：列表、搜索、虚拟滚动、窗口按钮
├── styles/theme.css
└── types.ts
```

## 已知限制

- 只记录文本和图片，复制文件（资源管理器里的文件）不会记录
- 剪贴板同时含文字和图片时（例如从 Excel 复制单元格区域），优先记文字，避免同一份内容存两条
- 没有开机自启开关，需要的话把 exe 快捷方式放进 `shell:startup` 目录
- 单张图片没有大小上限，超大图会按原样保存
- 便携版 exe 未做代码签名，首次运行可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」即可
- 仅支持 Windows

## 快捷键冲突

如果 `Ctrl+Shift+V` 被其他软件占用，启动日志会提示注册失败，此时只能通过托盘图标或再次启动程序来唤出窗口。
